    Plug in the real model

    Guppy runs on a stand-in brain here that writes replies the way a tuned model would. The bowl only calls one function, so the 68M model drops in by replacing it:

    brain.react = async (prompt) => {
  const res = await fetch("https://your-fish-server/generate", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ prompt, max_new_tokens: 48 }),
  });
  const { text } = await res.json();
  return text; // "<mood:scared> <act:hide> i hide now"
};

    Moods: content, curious, happy, hungry, scared, sleepy, grumpy. Acts: wander, approach, flee, hide, chase_food, sleep, loop, surface, sulk. A reply with no tags still works: the bowl guesses mood and act from keywords. Artifact pages cannot call outside servers, so the swap works once you host the bowl yourself.
